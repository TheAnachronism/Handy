# CLI `--lookahead` overrides Lookahead for one Plain Dictation start

OS keybinds already start Plain Dictation with `handy --toggle-transcription`. A companion `--lookahead fastest|fast|balanced|accurate` lets a second keybind use a different Lookahead without changing the Settings dropdown. The override applies only when that invocation **starts** a Dictation Session, only if Live Insertion is on and the model can stream, and only for that session. It is ignored on stop, on Post-Process Dictation, and when Live Insertion is off or the model cannot stream. It does not persist. `--lookahead` without a start flag is a usage error. No start-only `--transcribe` command in this slice. Overlay commit timing follows the same Lookahead as Direct typing. In-app hotkeys, tray, and Unix signals keep the Settings preset.
