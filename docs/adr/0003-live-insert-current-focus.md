# Live Insertion follows current keyboard focus

Each committed increment is typed into whatever currently has keyboard focus. The overlay is preview only and must not become the Target Application. The user can retarget mid-session by clicking another field. The Dictation Session stays open through silence; silence does not auto-stop or auto-finalize tentative text. Live Insertion applies in both push-to-talk and toggle; push-to-talk users who see modifier bleed should use toggle or a non-modifier hotkey.
