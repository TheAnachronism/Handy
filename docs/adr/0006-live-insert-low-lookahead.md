# Live Insertion uses a short Lookahead

When Live Insertion is on, Handy asks the loaded streaming model for a Lookahead so Committed Transcript appears sooner than Batch Insertion. When Live Insertion is off, streaming (overlay preview, Batch Insertion) keeps the model's accuracy-first default. Tentative Transcript still stays overlay-only; Lookahead only changes when text becomes committed, not what is typed. Non-streaming models keep Batch Insertion; Live Insertion does not apply.

The Lookahead preset is a setting next to Live Insertion (Fastest / Fast / Balanced / Accurate). Default is Fast: Nemotron Streaming 3.5 GGUF `att_context_right = 3` (~240 ms), the shortest non-zero entry on that model's training menu (`13 6 3 0`). Fastest is 0 ms; Balanced is 6 (~480 ms); Accurate is 13 (~1 s). Off-menu values such as 1 fail stream begin. For chunked Unified EN, the same preset maps onto the smallest-to-largest on-menu chunk and right; left stays large if the menu allows. Silence Feeding still applies whenever Live Insertion is on. If the stream extension is rejected, start with the model's default StreamOptions and still Live-Insert committed text.
